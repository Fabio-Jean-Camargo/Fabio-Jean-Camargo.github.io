# Portfólio – Fábio Jean Camargo

Site estático (HTML, CSS e JavaScript) para GitHub Pages.

## Publicar
1. Coloque o currículo na raiz com o nome `curriculo.pdf` (os botões "Currículo" e "Baixar currículo" apontam para ele).
2. Faça commit de tudo e envie ao GitHub.
3. Em Settings > Pages, escolha a branch `main` e a pasta `/ (root)`.

Se o repositório se chamar `Fabio-Jean-Camargo.github.io`, o endereço será `https://fabio-jean-camargo.github.io/`, que é o usado nas meta tags Open Graph do `index.html`. Com outro nome de repositório, atualize `og:url` e `og:image` no `index.html`.

## Estrutura
- `index.html`, `css/style.css`, `js/main.js`
- `images/web/` e `images/thumb/`: versões otimizadas (WebP) usadas no site
- `images/originais/`: imagens originais, intactas
- `images/og.jpg`: imagem de compartilhamento
